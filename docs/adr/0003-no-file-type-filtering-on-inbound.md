# 入站文件不做类型黑白名单，只管大小

落盘不等于执行。真正的执行闸门是 DSH 已有的工具审批，而类型名单绕过成本是改一个扩展名——把 `.sh` 拒了，同样的内容命名成 `notes.txt` 照样能被 `bash notes.txt` 跑起来。名单挡不住攻击，却会挡死真实场景：发个 `.zip` 让 agent 解压看里面的日志、发个 `.pdf` 或 `.xlsx` 让它读，都是一等一自然的诉求。所以唯一设防的维度是大小（单文件 + 单条消息两层配额），防的是意外塞盘，不是攻击。

写下这条是因为"为什么不限制文件类型"会被安全评审反复问到，而"加个黑名单"看起来永远像是免费的改进。它不是免费的：它买到的是安全感，付出的是能力。
